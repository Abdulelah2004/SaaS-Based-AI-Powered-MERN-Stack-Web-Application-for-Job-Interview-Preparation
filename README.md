# SaaS-Based AI-Powered MERN Stack Web Application for Job Interview Preparation

**Thesis Project | Abdulelah Mohammed Mohammed Ahmed | UNSIKA, Karawang | 2025**

---

## Overview

This project presents a **SaaS-based web application** designed to support job interview preparation through **AI-driven simulations**. Built with the **MERN stack (MongoDB, Express.js, React.js, Node.js)** and integrated with **Gemini AI**, the system generates context-aware interview questions, evaluates user responses in real time, and delivers personalized feedback.

The platform addresses common gaps in conventional preparation tools: static content, limited adaptability, and lack of real-time performance evaluation. This work combines academic rigor with practical deployment in a cloud-native environment.

---

## Features

* **AI-Powered Interview Generation:** Gemini AI generates role-specific technical and behavioral questions.
* **Real-Time Feedback:** Semantic analysis of responses with corrective recommendations.
* **Adaptive Learning:** Tracks user performance to tailor subsequent practice sessions.
* **SaaS Architecture:** Cloud-based deployment ensures accessibility across devices and locations.
* **Secure Authentication:** JWT-based login and session management.
* **Session Management:** Create, revise, delete, and retrieve interview sessions.

---

## Tech Stack

* **Frontend:** React.js, Vite, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB Atlas
* **AI Integration:** Gemini AI via REST API
* **Authentication:** JSON Web Tokens (JWT)
* **Deployment:** Netlify (frontend), Cloud server (backend)

---

## Research Context

* **Problem:** Traditional preparation tools fail to provide adaptive, personalized, and accessible support for candidates.
* **Objective:** Build a fully documented, academically grounded SaaS platform that integrates AI reasoning with full-stack engineering.
* **Methodology:** Waterfall SDLC model, including Planning, Requirement Analysis, System Design, Implementation, Testing, and Deployment.

## Installation & Setup

1. Clone the repository:

```bash
git clone <repo-url>
```

2. Install dependencies:

```bash
cd frontend && npm install  
cd ../backend && npm install
```

3. Configure environment variables for MongoDB Atlas and Gemini API.
4. Start frontend and backend:

```bash
npm run dev  # frontend  
node server.js  # backend
```
